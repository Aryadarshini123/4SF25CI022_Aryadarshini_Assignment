# Pandas Programs

## About
This repository contains 13 Python programs based on Pandas. These programs were done as part of my Data Science assignment to practise DataFrame operations and data manipulation.

## Libraries Used
- Python
- Pandas
- NumPy

## Programs Included
1. Creating a DataFrame and adding a new column.
2. Calculating row-wise and column-wise sums.
3. Handling missing values using mean.
4. Dropping rows containing null values.
5. Grouping data and calculating sum and mean.
6. Calculating total sales by category.
7. Merging two DataFrames.
8. Creating a MultiIndex DataFrame and performing indexing and slicing.
9. Grouping MultiIndex data.
10. Applying functions to DataFrame values.
11. Using lambda functions to calculate row-wise sums.
12. Converting strings to uppercase.
13. Extracting the first three characters from strings.

## Concepts Practised
- DataFrame and Series
- Data manipulation
- Null value handling
- Grouping and aggregation
- Merging
- MultiIndex
- Functions and lambda
- String operations

- `Pandas_Programs.ipynb` – Contains all 13 Python programs and their outputs.
